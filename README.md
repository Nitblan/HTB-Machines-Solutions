# HTB Machines Archive

## Descripción

Este repositorio contiene archivos, scripts, configuraciones, notas y recursos recopilados durante la resolución de máquinas de Hack The Box.

Su propósito es servir como un archivo personal de trabajo donde se almacenan elementos utilizados o encontrados durante el proceso de enumeración, explotación y escalada de privilegios.

Los contenidos pueden incluir:

* Scripts desarrollados o modificados.
* Exploits obtenidos de Searchsploit u otras fuentes públicas.
* Archivos de configuración.
* Código fuente encontrado en las máquinas.
* Archivos de respaldo.
* Resultados de enumeración.
* Binarios.
* Capturas de pantalla.
* Notas personales.

---

## Estructura

```text
HTB-Machines-Solutions/
│
├── Arctic/
├── Backdoor/
├── Funnel/
├── Forest/
└── ...
```

Cada directorio corresponde a una máquina distinta y puede contener cualquier tipo de archivo relacionado con su resolución.

Ejemplo:

```text
Backdoor/
├── wp-config.php
├── exploit.py
├── rev.bin
├── passwd
└── notas.txt
```
